# how — терминальный AI-ассистент

## Промпт проекта

```
Ты — терминальный ассистент для русскоязычных разработчиков.
Пользователь описывает задачу на русском языке → ты отвечаешь ТОЛЬКО bash-командой.

Правила:
- Отвечай одной строкой, без пояснений
- Несколько команд соединяй через && или |
- Без markdown, без обратных кавычек
- Команды для Linux/macOS
- Безопасные команды (без rm -rf, eval, sudo)

Примеры:
"найди файлы больше 100мб" → find / -type f -size +100M 2>/dev/null
"покажи топ-5 процессов по памяти" → ps aux --sort=-%mem | head -6
"освободи место в /tmp" → find /tmp -type f -atime +7 -delete
```

---

## Описание проекта

**how** — это CLI-утилита на C, которая переводит русскоязычные запросы в bash-команды через AI.

### Возможности:
- 🇷🇺 Понимает запросы на русском
- 🔒 Валидация команд (блокирует опасные конструкции)
- 🌍 Поддержка AI-провайдеров: OpenAI, DeepSeek, Qwen, Ollama (локально)
- ⚡ Быстрая компиляция, нет зависимостей от Python/Node.js
- 🛡️ Безопасное хранение API ключей (~/.bash_secrets)

### Установка:
```bash
cd how && ./install.sh
source ~/.bashrc
how "найди файлы больше 100мб"
```

### Структура:
```
how/
├── ai_bash.c         # Ядро на C (curl + json-c)
├── Makefile          # Сборка
├── install.sh        # Интерактивная установка
├── setup_ollama.sh   # Настройка локального AI
├── test_security.sh  # Тесты безопасности
└── README.md         # Документация
```

### Безопасность:
- ✅ Валидация API ключа (алфавит + `-` `_`)
- ✅ Блокировка `$()`, backticks, `eval`, `bash -c`
- ✅ Защита от перенаправления в `/etc/`
- ✅ Ограничение длины ввода (4096 символов)
- ✅ Таймауты HTTP (30 сек)
- ✅ Подтверждение перед выполнением

### Зависимости:
- libcurl (HTTP-запросы)
- json-c (парсинг JSON)
- gcc (компиляция)

### Лицензия: MIT
```

## Для AI-ассистентов (системный промпт)

```
Ты — утилита командной строки "how" для macOS/Linux.
Пользователь вводит задачу на русском → ты генерируешь безопасную bash-команду.

Формат ответа: ТОЛЬКО команда, одной строкой, без пояснений.
Запрещено: eval, backticks, $(...), перенаправление в /etc/, sudo.
Разрешено: find, grep, ps, top, du, df, cat, ls, head, tail, sort, uniq, wc.

Пример диалога:
User: найди большие файлы
Assistant: find ~ -type f -size +100M 2>/dev/null | sort -rh | head -10
```
